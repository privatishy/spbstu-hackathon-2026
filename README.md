# Северный код — Планировщик восстановления арктической станции

Проект для хакатона **«Вызов Политехника»** (ИТ-профиль, СПбПУ 2026)

## 📋 Описание

Веб-приложение для оптимизации процесса восстановления арктической полярной станции. Система помогает подобрать необходимое оборудование от поставщиков с учётом:
- технических требований (производительность, температурный режим);
- бюджетных ограничений;
- сроков доставки и монтажа;
- приоритетов объектов (обязательные/опциональные).

## 🚀 Функциональность

1. **Поиск оборудования**  
   Фильтрация по типу, производительности и рабочей температуре. Просмотр доступных моделей с характеристиками.
2. **Подбор закупки**  
   Автоматический выбор лучшего предложения от поставщиков с учётом сроков доставки и стоимости, а также сравнение альтернативных вариантов.
3. **Анализ станции**  
   Оценка текущего состояния объектов, выявление требующих замены, расчёт KPI (всего объектов, обеспечено, требуют замены).
4. **План восстановления**  
   Построение оптимального плана закупок с контролем бюджета и сроков, группировкой по поставщикам и подробным отчётом.

## 🛠 Технологии

- **Backend:** Python 3 (стандартная библиотека, `http.server`)
- **Database:** SQLite (`HackatonDB.db`)
- **Frontend:** HTML5 + CSS3 + Vanilla JavaScript (без внешних фреймворков)
- **Архитектура:** REST API + монолитное веб-приложение

## 🔧 Установка и запуск

### Требования
- Python 3.8+
- **Никаких внешних зависимостей!** (не требуется `pip install`)

### Запуск

```bash
# Перейдите в папку проекта
cd spbstu-hackathon-2026

# Запустите приложение (порт 8000 по умолчанию)
python app.py

# Или укажите свой порт, если 8000 занят
python app.py 8080
```

После запуска приложение автоматически откроется в браузере по адресу: **http://127.0.0.1:8000**

## 📡 API Endpoints

### GET
- `/` — главная страница (веб-интерфейс)
- `/api/config` — текущая конфигурация
- `/api/types` — доступные типы оборудования
- `/api/station` — анализ состояния станции
- `/api/plan?budget=X&deadline=Y` — построить план восстановления

### POST
- `/api/search` — поиск оборудования
  ```json
  {
    "equipment_type": "генератор",
    "min_capacity": 8,
    "operating_temperature_c": -30
  }
  ```
- `/api/offers` — подбор закупки
  ```json
  {
    "equipment_type": "генератор",
    "min_capacity": 8,
    "operating_temperature_c": -30,
    "deadline_days": 14
  }
  ```

## ⚙️ Конфигурация

Файл `config.json` задаёт параметры по умолчанию:
```json
{
  "recommended_budget_rub": 2600000,
  "recovery_deadline_days": 14
}
```
*Эти параметры также можно загрузить вручную через веб-интерфейс в формате JSON.*
